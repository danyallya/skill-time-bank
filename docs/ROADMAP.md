# Roadmap

1. Foundation — local shell, dependency lockfile and CI setup.
2. First safe domain slice — local offer drafts, proposed hours, validation and deletion; no interaction or agreement.
3. Durable workflow — PostgreSQL migrations and repository tests, then moderation, consent, retention, export and deletion rules.
4. Offline workflow — local writes, outbox, idempotency and conflict UX.
5. Release readiness — access control, audit, accessibility, backups, threat review and deployment.

Thin MVP estimate after foundation: 10-18 focused engineering days; excludes external approval.
